📦 50 Files — Kahan Jaati Hain?

Batch → Link → Delete → aur data ka poora safar

✅ Chhota jawab

Tumhari 50 files hamesha DB channel (-1004368401627) me safe rehti hain.
30 minute baad sirf user ke chat ki copies delete hoti hain — original kabhi nahi.
Link zinda rehta hai — user dobara click karega to phir se 50 files mil jayengi.

🔄 Poora Flow — step by step

[1] ADMIN: /batch → 50 videos bheji
         │
         ├─ bot har file ko DB CHANNEL me copy karta hai
         │     → channel me 50 asli messages ban gaye (id: 101…150)
         │
         └─ bot memory me list rakhta hai: [101,102,…,150]

[2] ADMIN: /done
         │
         ├─ code bana: Ab3xK9pQ2
         ├─ SQLite (/data) me save:
         │     code=Ab3xK9pQ2 · msg_ids=[101…150] · count=50
         │
         └─ link mila: t.me/HarshFSBot?start=Ab3xK9pQ2

[3] USER link kholta hai
         │
         ├─ bot SQLite se ids padhta hai → [101…150]
         ├─ DB channel se copy_message() — move nahi, COPY
         │     → DB channel me 50 abhi bhi hain ✓
         │     → user ke chat me 50 nayi copies ✓
         │
         └─ ⚠️ "30 min me delete — forward kar lo"

[4] 30 MINUTE BAAD
         │
         ├─ ✗ user ke chat ki 50 copies DELETE
         ├─ ✓ DB channel ki 50 original SAFE
         ├─ ✓ SQLite me record SAFE
         └─ ✓ link ABHI BHI kaam karta hai

[5] USER dobara link kholta hai
         └─ 50 files phir se mil gayi (step 3 repeat)

💾 /backup kya deta hai?

✅ Backup me hai

  • Saare users + ban status
  • Saare batch codes + message ids
  • Admins list
  • Settings (auto-delete, protect…)
  • Audit logs

Size: ~100 KB (1000 batches par bhi)

❌ Backup me nahi hai

  • Actual video files

Kyunki wo DB channel me hain — Telegram ke server pe. .db file me sirf unke address (message ids) hain.

Isliye: DB channel delete = files gayi, backup bhi bekaar.

⚠️ 3 cheezein jo kabhi mat karna
  • DB channel se messages delete — saare purane links dead ho jayenge
  • DB channel se bot ko remove — bot files copy nahi kar payega
  • Volume mount hatana — saare batch records, users, admins gayab
