⚑ Force Subscribe — Setup Guide

Koi bhi channel · public ya private · unlimited

Ek hi rule: bot ko us channel me admin banana padega. Bas itna. Telegram sirf admins ko batati hai ki koi user member hai ya nahi.

📋 Setup — 4 step

1

Bot ko channel me admin banao

Channel kholo → Administrators → Add Admin → apna bot search karke add karo.

Permissions me ye do zaroor on rakhna:

  • Invite Users via Link — bina iske invite link nahi banegi
  • Manage Channel (ya default admin rights)
2

Channel ki ID nikalo

Public channel? ID ki zaroorat nahi — seedha @username use kar lo.

Private channel? Channel me koi message bhejo → usko apne bot ko forward karo → bot me /id likho:

You:  /id
Bot:  ◉ ʏᴏᴜʀ ɪᴅ: 1763060393
      ◆ ᴄʜᴀɴɴᴇʟ ɪᴅ: -1001234567890  ← ye
3

Bot me add karo

/addfsub -1001234567890        ← private channel
/addfsub @moviehub              ← public channel
/addfsub -1001234567890 request ← join-request mode

Bot khud check karega: channel exists? bot admin hai? invite link ban sakti hai? — teeno sahi to confirm dega.

4

ON karo

Pehla channel add karte hi force sub apne aap ON ho jata hai.

Baad me band/chalu karna ho: /panel → ⚑ F-Sub toggle.

🎛 Do modes

🟢 Direct Join (default)

User ne channel join kar liya tabhi file milegi.

/addfsub -100xxx

Normal channels ke liye. Sabse aam.

🔵 Join Request

User ne request bhej di to kaafi hai — approve ka wait nahi.

/addfsub -100xxx request

Un channels ke liye jahan manual approval hoti hai. Member count badhta hai, user ko file bhi turant milti hai.

💡 Kaam ki baatein

  • Unlimited channels — jitne chaho add karo, sab join karne padenge
  • Admins ko chhoot — tumhe khud join nahi karna padega
  • Bot admin nahi? Wo channel silently skip ho jayega — user block nahi hoga
  • Groups bhi chalte hain, sirf channels nahi
  • User leave kar de? Agli baar link kholte hi phir se join maangega

❌ Common errors

"ʙᴏᴛ ᴀᴅᴍɪɴ ɴᴀʜɪ ʜᴀɪ"
Bot ko us channel me admin banao, phir dobara /addfsub karo.
"ᴄʜᴀɴɴᴇʟ ɴᴀʜɪ ᴍɪʟᴀ"
ID galat hai, ya bot ne kabhi us channel ko "dekha" nahi. Pehle admin banao — phir ID apne aap resolve ho jayegi.
"ɪɴᴠɪᴛᴇ ʟɪɴᴋ ɴᴀʜɪ ʙᴀɴᴀ"
Bot ko Invite Users via Link permission do.
User join karke bhi "join karo" dikh raha hai?
Bot ko channel se remove to nahi kar diya? Admin rights check karo. Bina admin ke bot membership verify hi nahi kar sakta.
